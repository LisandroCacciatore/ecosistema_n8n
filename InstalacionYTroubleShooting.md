Guía de Instalación y Troubleshooting (Namecheap + GCP + n8n)1. Configuración del Dominio (Namecheap)El error más común es una IP mal configurada o el tiempo de propagación.Registro A: Debe apuntar el host n8n a la IP Externa de tu VM de Google Cloud.Verificación: Usá herramientas como dnschecker.org para ver si n8n.tudominio.com ya muestra tu IP.Ojo con el Proxy: Si usaras Cloudflare en el futuro, recordá que para la primera validación de SSL con Caddy, la "nube naranja" debe estar apagada.2. Google Cloud: La "Aduana" (Firewall)Si el dominio apunta bien pero el navegador dice "Timed Out", el problema es el Firewall de GCP.Reglas de Red: Debés tener habilitados los puertos 80 (HTTP) y 443 (HTTPS).Prioridad: Si hay bloqueos, creá una regla manual con Prioridad 0 (la más alta) para la red default.Tags: Asegurate de que tu VM tenga los tags http-server y https-server en su configuración de red.3. Docker y la Comunicación InternaSi ves "Bad Gateway" o "Connection Refused", es un problema entre los contenedores.El archivo docker-compose.yml:Caddy: Debe apuntar al nombre del servicio (to n8n:5678).n8n: No debe estar restringido a 127.0.0.1. Usá ports: - "5678:5678".Listen Address: n8n debe tener la variable - N8N_LISTEN_ADDRESS=0.0.0.0 para escuchar tráfico que venga de Caddy.Redes: Ambos contenedores deben estar en la misma network (ej. n8n-network).4. Diagnóstico Rápido (Comandos de Oro)Si algo falla, ejecutá estos comandos en orden dentro de tu VM:Qué revisarComandoQué buscarLogs de SSLdocker logs caddy -fsuccessfully obtained certificateLogs de n8ndocker logs n8n -fn8n ready on 0.0.0.0, port 5678Test Internocurl -I http://localhost:5678/healthzHTTP/1.1 200 OKLimpieza Totaldocker-compose down && docker volume rm ...Borrar volúmenes de Caddy para reintentar SSL limpio5. ¿Por qué tarda en cargar al principio?Propagación DNS: Namecheap puede tardar de 5 a 30 minutos en avisarle a todo internet que tu IP cambió.Generación de Llaves: n8n genera llaves de encriptación y prepara la base de datos la primera vez.Certificado SSL: Caddy hace varios intentos. Si falla por el firewall, se "pone en penitencia" y espera unos minutos antes de reintentar.
